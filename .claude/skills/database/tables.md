# Tables (`lib/db/schemas/*.ts`, 22 tables)

Every timestamp is `withTimezone: true`. The 4 Better Auth tables use `mode: 'date'` (the
library reads/writes real `Date`s and compares `expiresAt`); all app tables use `mode: 'string'`
so JSON responses carry ISO strings. NN = not null. Cascade/no-action rationale is in
`schema-changes.md`.

## Better Auth (owned by the library; property names are load-bearing)

| Table           | PK               | Columns                                                                                 | FKs                    | Indexes                                              |
| --------------- | ---------------- | --------------------------------------------------------------------------------------- | ---------------------- | ---------------------------------------------------- |
| `users`         | `id` uuid random | `name` NN, `email` NN unique, `emailVerified` bool NN, `image`, `createdAt`/`updatedAt` | —                      | unique email                                         |
| `sessions`      | `id`             | `expiresAt` NN, `token` NN unique, `ipAddress`, `userAgent`, `userId` NN                | `userId→users` cascade | `sessions_user_id_idx`                               |
| `accounts`      | `id`             | `issuer` NN, `accountId` NN, `providerId` NN, `userId` NN, tokens, `password`           | `userId→users` cascade | unique `(issuer, accountId)`, `accounts_user_id_idx` |
| `verifications` | `id`             | `identifier` NN, `value` NN, `expiresAt` NN                                             | —                      | `verifications_identifier_idx`                       |

`id` is uuid (not Better Auth's default text) because `lib/auth/index.ts` sets
`advanced.database.generateId = () => crypto.randomUUID()`.
