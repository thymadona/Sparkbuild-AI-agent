Implementing Gravity & Collision

Now that we have our basic object structures, it's time to make them fall and bump into each other. A physics engine is all about updating positions based on velocity, and updating velocity based on acceleration (like gravity).

lightbulb The Goal

  • Apply a constant downward force (gravity) to all dynamic objects.
  • Implement a basic AABB (Axis-Aligned Bounding Box) collision check.
  • Reverse velocity upon collision to simulate a bounce.

Applying Gravity

In your update loop, add gravity to the y-velocity before updating the y-position.

physics.js

function updatePhysics(object, deltaTime) {
    const GRAVITY = 9.8;
    
    // Apply gravity to velocity
    object.velocityY += GRAVITY * deltaTime;
    
    // Update position based on velocity
    object.x += object.velocityX * deltaTime;
    object.y += object.velocityY * deltaTime;
    
    // Check floor collision
    if (object.y + object.height > canvas.height) {
        object.y = canvas.height - object.height;
        // Bounce! (Damping factor of 0.8)
        object.velocityY = -object.velocityY * 0.8;
    }
}
